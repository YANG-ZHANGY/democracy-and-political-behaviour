# 民主與政治行為

[English](README.md) · [Yang ZHANG](https://github.com/YANG-ZHANGY)

民主承諾、制度約束，以及公眾政治支持的內涵。

## 研究項目

| 項目 | 核心問題 |
| :--- | :--- |
| [反多元主義與公民空間](projects/anti-pluralism-and-civic-space.zh-Hant.md) | 政黨排斥多元主義時，什麼政治條件使它們有機會限制獨立組織？ |
| [民主支持與不受約束的領導](projects/democratic-support-and-leadership.zh-Hant.md) | 一個人同時支持民主與不受制度約束的領導者時，民主支持表達了什麼？ |
| [極化與在野支持者的交叉好感](projects/polarisation-and-opposition-affinities.zh-Hant.md) | 面對共同政治對手，是否也意味著對其他在野政黨抱持好感？ |
| [民主守門與政治接納](projects/democratic-gatekeeping.zh-Hant.md) | 主流政黨如何劃定合法競爭與威脅民主規則之間的界線？ |

## 研究取向

這個主題著重政治問題、制度機制及行為者之間的關係。各項目以易讀的文字介紹研究思路。
